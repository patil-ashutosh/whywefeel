# Why We Feel — Version 1

Static website for WhyWeFeel.in.

## Files
- index.html — homepage
- article-anger.html — first article
- style.css — responsive styling

## GitHub Pages
1. Create a new GitHub repository (for example `whywefeel`).
2. Upload these three website files and commit.
3. Open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide a temporary `github.io` URL.
7. After checking the site, configure the custom domain `whywefeel.in` in GitHub Pages.
8. In GoDaddy DNS, add the records GitHub Pages provides. Do not change other DNS records unnecessarily.
